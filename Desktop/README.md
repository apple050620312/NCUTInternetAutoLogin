# 桌面版使用說明

## 安裝

- Windows：開啟 `NCUT-Windows.exe`，完成安裝精靈。
- Linux：允許 `NCUT-Linux.AppImage` 執行，再開啟檔案。
- macOS：開啟 `NCUT-macOS.dmg`，將 App 拖入「應用程式」。

## 連線

填寫校園帳號與密碼，儲存後按「立即連線」。
開啟「自動重新連線」，App 會定期檢查並在需要時重新登入。
可選擇「登入電腦時啟動」，下次登入時自動在背景執行。

密碼只保留在此裝置。更改密碼時輸入新密碼再儲存；留空則保留原密碼。
關閉視窗後仍會在背景執行。系統匣選單可以重新開啟視窗、暫停或結束程式。

「等待網路連線」時先確認 Wi-Fi 或網路線；「登入未完成」時確認帳號密碼。
連線紀錄可查看最近狀態，也可以清除。

Windows/macOS 初次開啟可能顯示未驗證發行者提示，請確認檔案來自本專案 Release。
Linux 如果無法保存密碼，請確認桌面密碼管理員已解鎖。
